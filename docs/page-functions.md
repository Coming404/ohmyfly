# 五页功能分工

五个底部入口已确定为：**概览 → 订阅 → 测速 → 节点库 → 设置**。固定品牌顶栏显示当前页面，底栏使用 Miuix 悬浮胶囊。

下表是功能边界规划，不是全部已实现清单；具体业务分阶段接入。

| 页面 | 核心职责 | 规划功能 | 主要动作 |
|---|---|---|---|
| 概览 | 看全局与最近状态 | 订阅/有效节点数量、协议/地区概况、最近测试摘要、当前任务状态、功能快捷入口 | 打开当前任务、查看最近结果 |
| 订阅 | 管节点来源 | URL添加、文件/文本导入、手动刷新、编辑/删除来源、导入错误与数量、重复/不支持统计 | 添加、导入、刷新、更多 |
| 测速 | 执行测试并看本次结果 | 测试范围/目标确认、延迟预检、下载吞吐、开始/停止、逐节点进度、流量/错误提示、本次详细结果及历史查看入口 | 开始、停止、查看结果、导出（后续） |
| 节点库 | 管具体节点 | 汇总来源节点、名称/协议/来源详情、搜索、分类/协议/来源筛选、排序、多选、当前范围全选、加入测试队列 | 搜索、筛选/排序、批量选择 |
| 设置 | 管默认行为 | 明暗模式、减少透明效果、测试目标/超时/体积/并发、流媒体与AI偏好、订阅过滤、GitHub镜像、数据隐私与关于 | 参数保存/重置、镜像测延迟/排序/选择及降级验证 |

## 职责边界

- 订阅是来源，节点库是解析后的节点；刷新来源与挑选具体节点不混在一页。
- 节点库的选择进入测速页；测速不修改订阅来源。
- 概览只呈现摘要，不重复完整订阅列表、节点库或测速配置表单。
- 当前保留概览，不增加独立的第六个“结果”菜单。结果能力尚未实现，完整历史形态仍可在接入持久化时细化。
- 设置管理默认值；一次测试采用的实际参数必须在该次测试中可查，不能让后改默认值篡改历史条件。

## 当前代码状态

- 导航：五个具名目的地、左上悬浮品牌、五项悬浮导航，顶底共用材质参数；所有列表视口可延伸到浮层下方。
- 概览：实际目录数量与选择数量、功能入口、最近结果空状态；不填充假测量结果。
- 订阅：正式空状态；解析、刷新、文件读取和安全存储尚未接入。
- 测速：显示当前实际选择，跳转节点库；引擎未接通前开始按钮禁用。
- 节点库：摘要、分类、多选与批量选择；初始目录为空，尚无导入来源、搜索排序或持久化。
- 设置：七入口分组首页；外观与测速／流媒体AI／订阅配置由DataStore持久化。GitHub镜像支持列表编辑、真实HTTP小样本校验／延迟排序及手动优先失败降级验证；节点与媒体核心仍未接通。详见[设置与镜像](settings.md)。
- 配色：Android系统动态色且无固定种子，iOS默认浅深色回退，不声称读取iOS壁纸。

本地静态与Python检查不证明共享 Kotlin 编译或真机效果。完整构建只在用户要求新包时触发，不自动下载安装包。
