# 五页功能分工

五个底部入口已确定为：**概览 → 塔台 → 起飞 → 航班 → 设置**。通用顶部使用18sp紧凑标题；塔台与航班使用页面内34sp大标题及搜索操作，宿主不重复页名。子页使用纯图标返回；底栏为24dp平滑轮廓的悬浮容器，上图标下文字、五个标签常显，选中加粗。

下表是功能边界规划，不是全部已实现清单；具体业务分阶段接入。

| 页面 | 核心职责 | 规划功能 | 主要动作 |
|---|---|---|---|
| 概览 | 看全局与最近状态 | 塔台/有效航班数量、协议/地区概况、最近测试摘要、当前任务状态、功能快捷入口 | 打开当前任务、查看最近结果 |
| 塔台 | 管航班来源 | URL添加、文件/文本导入、手动刷新、编辑/删除来源、导入错误与数量、重复/不支持统计 | 添加、导入、刷新、更多 |
| 起飞 | 执行测试并看本次结果 | 测试范围/目标确认、延迟预检、下载吞吐、开始/停止、逐航班进度、流量/错误提示、本次详细结果及历史查看入口 | 开始、停止、查看结果、导出（后续） |
| 航班 | 管具体航班 | 汇总来源航班、名称/协议/来源详情、搜索、分类/协议/来源筛选、排序、多选、当前范围全选、加入测试队列 | 搜索、筛选/排序、批量选择 |
| 设置 | 管默认行为 | 明暗模式、界面材质、减少透明效果、测试目标/超时/体积/并发、流媒体与AI偏好、塔台过滤、GitHub镜像、数据隐私与关于 | 参数保存/重置、镜像测延迟/排序/选择及降级验证 |

## 职责边界

- 塔台是来源，航班页是解析后的航班；刷新来源与挑选具体航班不混在一页。
- 航班页的选择进入起飞页；起飞不修改塔台来源。
- 概览只呈现摘要，不重复完整塔台列表、航班页或起飞配置表单。
- 当前保留概览，不增加独立的第六个“结果”菜单。结果能力尚未实现，完整历史形态仍可在接入持久化时细化。
- 设置管理默认值；一次测试采用的实际参数必须在该次测试中可查，不能让后改默认值篡改历史条件。

## 当前代码状态

- 导航：五个具名目的地、紧凑页名及设置子页纯图标返回；底栏恢复旧版五项等宽 G2 玻璃胶囊并使用 Clear face/blur。按压绘制 G2 扩散 BloomStroke、指尖光斑和内环阴影；拖动阻尼跟手并弹簧吸附。顶栏和选择态工具胶囊同步 Clear 材质，40dp按钮图标/标签统一复用尺寸 token。
- 导航层次：五个一级入口切换不入栈；设置首页通过 Miuix NavDisplay 与唯一可保存 NavBackStack 打开六个业务子页和液态玻璃调节页，纯图标返回读栈，LTR/RTL滑退按栈方向工作。镜像编辑时阻断页面滑退，返回先关闭表单。
- 概览：实际目录数量与选择数量、功能入口、最近结果空状态；不填充假测量结果。
- 塔台：已接本地目录、链接/文件/正文导入、名称搜索、单个/全部网络同步、来源航班、删除撤销及错误反馈。布局为大标题操作、紧凑统计同步栏、来源/状态卡与底部添加面板；本地来源的更新方式见[塔台与航班使用](towers-flights.md)。
- 起飞：显示当前实际选择，跳转航班页；引擎未接通前开始按钮禁用。
- 航班：已接目录连续窗口、搜索/协议等即时筛选、已加载项选择、真实性能摘要、平台品牌图标及折叠连接/历史详情。无数据时显示空态；长按航班可选择，读屏提供选择动作；起飞引擎仍未接通。
- 设置：外观区配置明暗、液态玻璃/Expressive界面风格与减少透明/动态效果；仅Expressive显示自动项及7个配色种子。Android自动跟随系统动态代表色，iOS Expressive自动使用产品蓝；液态玻璃忽略手选种子。液态玻璃模式另提供实际色层Alpha与模糊半径dp的无级调节页，初值读取Miuix当前配方，可恢复默认；材质设置由DataStore持久化。全局Snackbar按状态显示图标并原样呈现成功文案；塔台/过滤、测试、镜像和应用信息保留子页入口。

本地静态与Python检查不证明共享 Kotlin 编译或真机效果。完整构建只在用户要求新包时触发，不自动下载安装包。
