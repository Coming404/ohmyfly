# 五页功能分工

五个底部入口已确定为：**概览 → 塔台 → 起飞 → 航班 → 设置**。顶部为18sp紧凑页面标题，子页使用纯图标返回，不再显示重复品牌胶囊；底栏为24dp平滑轮廓的悬浮容器，上图标下文字、五个标签常显，选中加粗。

下表是功能边界规划，不是全部已实现清单；具体业务分阶段接入。

| 页面 | 核心职责 | 规划功能 | 主要动作 |
|---|---|---|---|
| 概览 | 看全局与最近状态 | 塔台/有效航班数量、协议/地区概况、最近测试摘要、当前任务状态、功能快捷入口 | 打开当前任务、查看最近结果 |
| 塔台 | 管航班来源 | URL添加、文件/文本导入、手动刷新、编辑/删除来源、导入错误与数量、重复/不支持统计 | 添加、导入、刷新、更多 |
| 起飞 | 执行测试并看本次结果 | 测试范围/目标确认、延迟预检、下载吞吐、开始/停止、逐航班进度、流量/错误提示、本次详细结果及历史查看入口 | 开始、停止、查看结果、导出（后续） |
| 航班 | 管具体航班 | 汇总来源航班、名称/协议/来源详情、搜索、分类/协议/来源筛选、排序、多选、当前范围全选、加入测试队列 | 搜索、筛选/排序、批量选择 |
| 设置 | 管默认行为 | 明暗模式、界面材质、减少透明效果、测试目标/超时/体积/并发、流媒体与AI偏好、塔台过滤、GitHub镜像、数据隐私与关于 | 参数保存/重置、镜像测延迟/排序/选择及降级验证 |

## 职责边界

- 塔台是来源，航班页是解析后的航班；刷新来源与挑选具体航班不混在一页。
- 航班页的选择进入起飞页；起飞不修改塔台来源。
- 概览只呈现摘要，不重复完整塔台列表、航班页或起飞配置表单。
- 当前保留概览，不增加独立的第六个“结果”菜单。结果能力尚未实现，完整历史形态仍可在接入持久化时细化。
- 设置管理默认值；一次测试采用的实际参数必须在该次测试中可查，不能让后改默认值篡改历史条件。

## 当前代码状态

- 导航：五个具名目的地、18sp紧凑页名、子页纯图标返回；底栏为24dp平滑容器，24dp图标在上/11sp标签在下、标签常显、选中Bold且五等宽。顶部实际功能控件与底栏共用原模糊参数，仅轮廓不同；App唯一目的地状态与所有列表视口延伸行为保持。
- 导航层次：五个一级入口切换不入栈；设置首页到六子页由Miuix NavDisplay与唯一可保存NavBackStack接管，纯图标返回读栈，官方MiuixDefault转场及LTR/RTL滑退已源码接线。镜像编辑时阻断页面滑退，返回先关闭表单；液态玻璃材质由共享ui/glass实现，不由NavDisplay承担。
- 概览：实际目录数量与选择数量、功能入口、最近结果空状态；不填充假测量结果。
- 塔台：正式空状态；解析、刷新、文件读取和安全存储尚未接入。
- 起飞：显示当前实际选择，跳转航班页；引擎未接通前开始按钮禁用。
- 航班：摘要、分类、多选与批量选择；初始目录为空，尚无导入来源、搜索排序或持久化。
- 设置：紧凑品牌身份区、首页外观选择菜单/开关与六个子页入口；外观与起飞／流媒体AI／塔台配置由DataStore持久化。新增界面材质四项选择（高斯模糊/高光玻璃/柔光玻璃/液态玻璃），默认液态玻璃，减少透明效果控制实体回退；四项已接入共享玻璃预设与双端倾斜高光；尚未原生编译或真机验收。GitHub镜像支持列表编辑、真实HTTP小样本校验／延迟排序及手动优先失败降级验证；航班与媒体核心仍未接通。详见[设置与镜像](settings.md)。
- 配色：Android系统动态色且无固定种子，iOS默认浅深色回退，不声称读取iOS壁纸。

本地静态与Python检查不证明共享 Kotlin 编译或真机效果。完整构建只在用户要求新包时触发，不自动下载安装包。
