状态：**十项修订已落本地源码；结构检查和75项Python静态测试通过，178项Kotlin shared测试已声明但未执行。本轮未本地编译，双端Actions及真机验收待进行。** R2 九张 PNG 与[带 11 条连线的总览](screenshots/mirror-overview.png)记录初版讨论，不覆盖以下最新行为。用户最新决定高于图片和旧笔记。

## 1. 范围与最新决定

仅实施第 8 项中的 GitHub 镜像源页，其他设置页重设计及其余真机反馈仍未实施。页面 ID 表示逻辑状态，不增加九个导航路由。复用现有根 Miuix Scaffold、SettingsSession、DataStore、探测与安全验证，不搬入网页评审工具或示例数据。

- 实际 App 的拼接方式行显示链路图标＋“拼接方式”，右侧只读显示 HTTP(S) 前缀，无下拉与箭头（U11 已删除模板格式）。“名称”“拼接方式”“地址”“改写预览”四个标题及右侧 HTTP(S) 前缀值统一为 13sp Normal、主题前景色 `MiuixTheme.colorScheme.onSurface`（随明暗主题切换，不用固定黑色）；标题前图标保持 16dp、`onSurfaceVariantSummary` 灰色，与文字均相距 8dp。输入框文字保持 14sp，预览框内改写结果正文保持 12sp；二者共用 `TextFieldDefaults.textFieldColors().backgroundColor`。
- 全量测试成功完成后，自动选择有有效毫秒值的最低延迟镜像；手动选择继续有效，直到下一轮完整测试。失败／未测镜像留在列表尾部；显示结果按延迟升序，不改实际镜像资源的回退顺序。
- 选择管理 ⋯ 后用 Miuix `OverlayIconDropdownMenu` 呈现“测试／编辑／删除”，不再用管理模态或提供上移／下移。
- 镜像页弹窗使用 Miuix 默认 `windowDimming` 半透明灰幕，弹窗加 18dp 阴影；背景不再高斯模糊。新增／编辑与删除确认仍用同一个 OverlayDialog。
- 延迟状态使用 ≤100ms 绿色、101–300ms 琥珀色、>300ms 红色；失败仍为错误红色，未测／运行／排队保留独立状态。
- 五个主目的地由 `HorizontalPager` 配合 Miuix `springAnimateToPage` 统一程序化切页；设置子页继续使用 Miuix NavDisplay 默认弹簧转场。减少动态时改为直接切页。
- Miuix 0.9.4 的 `MiuixTheme` 已在全应用设置 `MiuixOverscrollFactory`；LazyColumn、verticalScroll、horizontalScroll 等标准容器沿用该主题回弹，不叠加第二种过界修饰器。

### 主列表

- 左上独立浮动返回、右上同规格 ＋，同一 materialMode 和减少透明策略。返回右侧无重复页名；内容标题 GitHub 图标＋“GitHub 镜像”出现一次，字号 18sp Semibold，与设置子页标题统一。
- 启用镜像开关保持可操作，即使当前列表为空；关掉后镜像列表、排序/管理入口、恢复草稿、批量测试和右上 ＋ 均禁用并显示轻灰遮罩，开关本身不遮罩。若批量测试正在运行，停止操作仍可用。
- 镜像源卡头：List 图标＋13sp Medium“镜像源”，不显示排序控件。显示列表始终按成功延迟升序，所有失败、未测试结果留在尾部；列表展示排序不改设置存储顺序，也不改资源请求回退顺序。
- 镜像行：单选→名称／域名→简短结果→唯一 ⋯。管理下拉只有测试／编辑／删除；点 ⋯ 不顺带选择。全量测试成功结束后自动选择有数值的最快镜像；单项测试与停止批次不触发自动选择。
- 名称 15sp Normal、输入与当前值14sp、结果／错误12sp；页面外距约16dp。未测试浅灰、失败红色、实测耗时随阈值绿／琥珀／红三档，排队／运行主色；真实错误详情保留读屏语义。长名／地址省略而非挤出容器，完整文本可读屏。
- 底部固定一个测试全部／停止按钮，图标与文字使用8dp间距；不显示单独的“重试失败项”按钮。空列表为背景上的图标和加粗提示，不套空卡片或重复放新增按钮。

### 弹窗与菜单

行尾管理使用 Miuix 0.9.4 `OverlayIconDropdownMenu`，锚定 More 图标，只有测试／编辑／删除三项，不再打开管理大弹窗，不提供镜像手动上移／下移。编辑仍使用 `OverlayDialog`，删除使用 `OverlayDialog` 确认；不使用 BottomSheet、不新增第三级子页。弹窗沿用 Miuix DialogDefaults 默认表面，使用 Miuix 默认 `windowDimming` 半透明遮罩，外加18dp黑色软阴影。

弹窗期间页面背景保持清晰，不叠加高斯模糊。官方弹窗接管系统返回，弹窗期间禁用页面滑退。

编辑顺序：名称→拼接方式只读行（链路图标，右侧显示 HTTP(S) 前缀，无下拉与箭头）→单行地址→只读改写预览→必要错误。四个标题及前缀值均为 13sp Normal、`onSurface`；标题图标灰色与 8dp 图文间距不变。输入文字 14sp、预览正文 12sp 不变，输入框和预览共用 TextFieldDefaults.textFieldColors() 的 backgroundColor。底部固定保存，不随内容滚出。字段参考最小44dp，允许系统大字增高；长地址水平编辑，预览可换行复制。键盘出现时限制弹窗高度并滚动内容，不打开全高子页。

标准 Compose LazyColumn、verticalScroll 与 horizontalScroll 均处于根 MiuixTheme 提供的 MiuixOverscrollFactory 下；不再为同一容器重复添加 overScrollVertical 修饰器。五个主目的地通过 Miuix springAnimateToPage 导航；设置内部 NavDisplay 保留 MiuixDefault 弹簧栈转场。减少动态模式禁用空间切页动画。

## 3. 字段与安全

名称为1–64可见字符，裁剪首尾空白；地址只在点击保存时规范化落盘。HTTPS 默认443、HTTP默认80去除，非默认端口保留，路径大小写保留；裸域名与显式同一HTTPS前缀按统一规范去重。不同协议不混为一项。

只放宽镜像端点，原始 GitHub 资源仍是固定公开 HTTPS 来源，不允许带凭据／查询令牌转发。拒绝未知协议、用户名密码、fragment、私网／保留地址及不安全 DNS；每次连接／跳转重新校验。HTTP同源与HTTP→HTTPS同主机升级允许，HTTPS→HTTP降级拒绝；跨站只允许已核实 GitHub HTTPS CDN。保留超时、大小、重定向次数和固定样本摘要校验。

Android cleartext 与 iOS ATS 为用户动态 HTTP 域名开放；HTTP 本身不加密，不承载私有资源或认证数据。iOS NSURLSession 二次DNS解析不能完全钉住，保留既有复绑定限制说明。无新增依赖、不升级 SDK 或最低系统。

## 4. 操作契约与时序

| ID | 行为 | 失败与恢复 |
|---|---|---|
| I-M01 | 开关立即反馈，经同一 Session 顺序事务持久化 | 列表为空也允许开启，空列表请求继续安全直连 |
| I-M02 | 整行选择稳定ID；停用时选择、管理、恢复草稿与探测按钮灰显、不可点并遮罩 | 开关本身可用；重新启用后恢复选择 |
| I-M03 | 始终按已测延迟升序显示，失败与未测留在尾部；列表排序不改实际镜像回退顺序 | 全量测试完整结束后自动选最低成功延迟；单项测试、停止、全失败不自动切换 |
| I-M04 | 测试全部仅探测镜像，失败后仍保留原完整测试按钮 | 不出现额外“重试失败项”；运行中停止仍可用 |
| I-M05 | ＋创建会话内稳定ID草稿，不插入列表 | 同稿可继续；仅保存确认后成为正式行 |
| I-M06 | ⋯ 打开官方图标操作下拉，含测试／编辑／删除；删除确认后锁定稳定ID | 操作关闭恢复入口键盘焦点；读屏焦点需设备验证 |
| I-M07 | 输入只改草稿，保留游标／合成态 | 不因业务回流覆盖输入 |
| I-M08 | 点击保存整体校验，同ID原子增改 | 保存中禁重复和编辑；真实读回确认成功才关闭 |
| I-M09 | 拼接方式只读显示 HTTP(S) 前缀，不改草稿、不展开下拉 | 无选项浮层可收起；外点／返回按编辑弹窗关闭契约处理，不保存 |
| I-M10 | 按100ms／300ms阈值显示绿色、琥珀色、红色色阶；主目的地统一 Miuix 弹簧切页，减少动态时直接切换 | 阈值只影响视觉；误差/未测状态不依赖颜色作为唯一提示，标准滚动由 MiuixTheme 默认回弹 |
| I-M11 | 保留／删除确认；当前项回剩余首项 | 最后一项删除＋关闭开关原子执行，失败不丢条目 |
| I-M12 | 关闭／外点／返回只保稿、不写盘 | 回原滚动位置；整个页面销毁不承诺保稿到重启 |

```text
输入（不写盘）
  ├─ 关闭／失焦／键盘完成／返回 → 不提交，草稿保留
  └─ 点击保存 → 完整校验
        ├─ 无效 → P-M06、保留输入
        └─ 同一 Session.changeConfirmed 顺序事务
              ├─ Confirmed → 确认候选一致后关闭
              ├─ Failed／Rejected → P-M08，保稿可再次保存
              └─ Uncertain → 只读保护，只重试读取，不重复新增
```

- 列表始终按已测成功延迟升序；全量测试完成后自动选择最低有效毫秒值，单项与已停止测试不自动选择。仅展示排序，不改 DataStore 源列表顺序或请求失败回退优先级。
- 新增排序模型及 `mirror.order` 只显示偏好字段已移除；历史排序 key 在首次常规设置写入时清除，其余镜像字段仅保持当前 HTTP(S) 前缀格式，不再兼容旧模板等旧格式。
- `MirrorProbeRunner` 由 `AppContent` owner 持有；镜像导航离开再返回时，已测结果、错误和相位不重建、不清空。只有 App owner coroutine scope 销毁时取消仍运行的探测。
