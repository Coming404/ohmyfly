# GitHub 镜像页重设计 · 第 8 项局部规格

状态：**原生源码已接入，待轻量检查收尾与双端验收**。视觉基准为 R2 九张独立 PNG 和[带 11 条连线的总览](screenshots/mirror-overview.png)；[原始线框](index.html)保留用户批注。用户最新决定高于图片中的旧行为，不为同步截图覆盖原始评审证据。

## 1. 范围与最新决定

仅实施第 8 项中的 GitHub 镜像源页，其他设置页重设计及其余真机反馈仍未实施。页面 ID 表示逻辑状态，不增加九个导航路由。复用现有根 Miuix Scaffold、SettingsSession、DataStore、探测与安全验证，不搬入网页评审工具或示例数据。

用户最新决定：
- 实际 App 的“拼接方式”为普通设置行，**不带独立卡片背景、边框、圆角**。
- 新增／编辑弹窗底部有**保存**按钮。只有点击保存才验证并提交；输入、失焦、IME 完成、关闭、外点、返回都不保存。草稿由页面 owner 保留。
- 镜像地址接受 HTTP、HTTPS、带或不带 www 的域名。未写协议默认 HTTPS，www 不强行增删；显式 HTTP 不改为 HTTPS。
- **移除直连条目**。关闭功能只走直连；开启后先选中镜像，再按持久化顺序尝试其余镜像，全部失败后才直连。未选或旧选择失效时优先首个镜像，取消请求不降级。
- 删光镜像时同一事务关闭镜像功能。空列表只提供**GitHub 图标＋Bold“暂无镜像源”**，无额外添加按钮；右上 ＋ 仍为新增入口，空列表不显示测试栏。
- iOS 设置输入框不弹出 Select／Select All 等系统浮动菜单；限制仅包输入框，不影响 Android 和只读预览的复制能力。

图内 A／B／C、example 地址、186／342ms 为线框示例，不能填入真实 App。排序默认保持既有 LatencyAscending，不因图片手动箭头重置用户偏好。

### 主列表

- 左上独立浮动返回、右上同规格 ＋，同一 materialMode 和减少透明策略。返回右侧无重复页名；内容标题 GitHub 图标＋“GitHub 镜像”出现一次。
- 启用镜像开关有电源图标，整行和 Switch 共用单一点击语义。停用不清空配置，行选择禁用但手动探测／编辑仍可用；空列表开关不可启用。
- 镜像源卡头：List 图标＋13sp Medium“镜像源”，右侧纯箭头，44dp 最小触区。手动→耗时低到高→耗时高到低→手动；不弹出排序菜单。当前／下一态通过语义提供。
- 镜像行：单选→名称／域名→简短结果→唯一 ⋯。点 ⋯ 不顺带选择，不保留行内测试／编辑／移动／删除按钮。
- 名称 15sp Normal、输入与当前值14sp、结果／错误12sp；页面外距约16dp。未测试浅灰、失败红色、实测耗时正常前景色，排队／运行主色；真实错误详情保留读屏语义。长名／地址省略而非挤出容器，完整文本可读屏。
- 底部固定测试全部／停止栏，最后一行有避让；重试失败项仅在有真实失败时出现。空列表为背景上的图标和加粗提示，不套空卡片或重复放新增按钮。

### 弹窗

管理、编辑／新增、删除共用一个 OverlayDialog，居中圆角、同一根 Scaffold；不使用 BottomSheet、不新增第三级子页。所有前景读取同一四材质设置，高斯模糊／高光玻璃／柔光玻璃／液态玻璃；减少透明或 shader 不可用时实体回退。

背景无灰幕，仅下方镜像页轻度景深；输入屏障拦截点击。打开至退场结束保留景深，快速重开不撤仍使用的效果；前景清晰，不叠第二份全页模糊。官方弹窗接管系统返回，页面自有 PredictiveBackHandler 已删除；弹窗期间禁用页面滑退。

管理标题为条目名＋GitHub 图标、右上关闭；测试／编辑／上移／下移／删除一行一个动作，图标块＋15sp文字。边界或非手动排序时移动禁用；删除红色。

编辑顺序：名称→普通拼接行→单行地址→只读改写预览→必要错误；底部固定保存，不随内容滚出。字段参考最小44dp，允许系统大字增高；长地址水平编辑，预览可换行复制。键盘出现时限制弹窗高度并滚动内容，不打开全高子页。

拼接选项作为同一弹窗内的覆盖区域，唯一 HTTP(S) 前缀带勾；外点／返回先收起选项，不穿透关闭父弹窗。旧模板显示“原模板”，直到用户明确选择前缀才改变草稿模式，原模板标记不得通过前缀校验。

## 3. 字段与安全

名称为1–64可见字符，裁剪首尾空白；地址只在点击保存时规范化落盘。HTTPS 默认443、HTTP默认80去除，非默认端口保留，路径大小写保留；裸域名与显式同一HTTPS前缀按统一规范去重。不同协议不混为一项。

只放宽镜像端点，原始 GitHub 资源仍是固定公开 HTTPS 来源，不允许带凭据／查询令牌转发。拒绝未知协议、用户名密码、fragment、私网／保留地址及不安全 DNS；每次连接／跳转重新校验。HTTP同源与HTTP→HTTPS同主机升级允许，HTTPS→HTTP降级拒绝；跨站只允许已核实 GitHub HTTPS CDN。保留超时、大小、重定向次数和固定样本摘要校验。

Android cleartext 与 iOS ATS 为用户动态 HTTP 域名开放；HTTP 本身不加密，不承载私有资源或认证数据。iOS NSURLSession 二次DNS解析不能完全钉住，保留既有复绑定限制说明。无新增依赖、不升级 SDK 或最低系统。

## 4. 操作契约与时序

| ID | 行为 | 失败与恢复 |
|---|---|---|
| I-M01 | 开关立即反馈，经同一 Session顺序事务持久化 | 失败回已确认值；空列表禁用开启 |
| I-M02 | 整行选择稳定ID，不启动测试 | 重复当前项不重复写；失败恢复 |
| I-M03 | 三态展示排序，不改持久化手动优先级 | 操作弹窗／滚动期间暂缓重排 |
| I-M04 | 测试全部仅探测镜像，有限并发 | 停止保留已完成，未完成标已停止；清理完成前不重开 |
| I-M05 | ＋创建会话内稳定ID草稿，不插入列表 | 同稿可继续；仅保存确认后成为正式行 |
| I-M06 | ⋯打开管理并锁定稳定ID | 关闭恢复入口键盘焦点；读屏焦点需设备验证 |
| I-M07 | 输入只改草稿，保留游标／合成态 | 不因业务回流覆盖输入 |
| I-M08 | 点击保存整体校验，同ID原子增改 | 保存中禁重复和编辑；真实读回确认成功才关闭 |
| I-M09 | 唯一拼接选项只改草稿 | 外点／返回先收下拉，不保存 |
| I-M10 | 手动时一次上／下移一位 | 边界禁用，失败回已确认顺序 |
| I-M11 | 保留／删除确认；当前项回剩余首项 | 最后一项删除＋关闭开关原子执行，失败不丢条目 |
| I-M12 | 关闭／外点／返回只保稿、不写盘 | 回原滚动位置；整个页面销毁不承诺保稿到重启 |

```text
输入（不写盘）
  ├─ 关闭／失焦／键盘完成／返回 → 不提交，草稿保留
  └─ 点击保存 → 完整校验
        ├─ 无效 → P-M06、保留输入
        └─ 同一 Session.changeConfirmed 顺序事务
              ├─ Confirmed → 确认候选一致后关闭
              ├─ Failed／Rejected → P-M08，保稿可再次保存
              └─ Uncertain → 只读保护，只重试读取，不重复新增
```

`settings`可能领先磁盘，不能用列表相等认定保存成功；`confirmedSettings`只来自读取，探测只使用已确认配置。更改地址／方式、删除后失效旧结果；迟到结果按run／条目版本隔离，纯改名可保留结果。取消不伪装IO失败。
