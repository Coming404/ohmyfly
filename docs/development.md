- [UI 展示页](ui-showcase.md)：概览/节点/外观底部导航，卡片、图标按钮、分类多选、主题切换和轻量动画；只用演示数据。

## 尚未证明

- Kotlin/AGP/Compose/Miuix整体能在云端编译。
- iOS16和Android13最低系统真机运行正常。
- Go核心能跨平台链接、测速、取消并释放全部资源。
- 许可、签名和分发路径已确定。

## 推荐执行

1. 在已创建的私有仓库推送并运行轻量检查；不在本地下载完整构建工具。
2. 手动触发 [双端真机 Release 构建](release-builds.md)，先修复依赖/DSL/SDK/Xcode问题，不堆业务代码。
3. 安装测试签名的 Android Release APK；iOS 真机 IPA 由用户自行重签后在16.x设备验收。AAB、xcarchive 和符号包不是直接安装包。
4. 确定Go工具链及一个Mihomo版本，做最小任务+事件+取消+释放的双端桥接。
5. 逐项接订阅解析与去重，使用固定样本保护密码大小写、组合凭证、Reality short-id、cipher和路径查询参数。
6. 确定页面信息架构与视觉令牌，再实现订阅、节点、测速、设置。

默认不增加导航/DI/数据库/图片库。确有需求时先按照AGENTS.md查询Klibs与官方资料，记录选择，不为使用某种架构先装整套依赖。
