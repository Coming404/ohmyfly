# 塔台与航班使用

## 添加与更新来源

塔台页右上角“添加”打开底部面板，支持订阅链接、文本及配置文件。

- **链接**：每行一个 HTTP(S) 地址，重复地址在同批合并；单个“同步”和“全部同步”均使用受限来源工作池。
- **文件**：Android/iOS 系统选择器支持多选。选择时只保存本次引用，轮到来源执行时才读取 UTF-8 正文，避免整批文件同时常驻内存。取消系统选择保留原有草稿。
- **文本**：粘贴配置正文或单节点链接。切换链接、文件、文本模式保留各自草稿，确认时一起提交。

“合并为一个塔台”默认关闭，关闭时每个来源独立建塔台；开启后显示一个塔台并持久保存全部来源。合并塔台的同步更新其中的网络地址，本地来源在“更多”中的来源列表按来源 ID 重新导入。一个来源失败保留其上次成功节点，不清空其他来源。来源之间仍执行基础 ContentHash 去重，来源身份和节点关联分别保存。合并塔台不相加不同套餐的流量额度。

文件和文本来源分别使用 `local:file:UUID`、`local:text:UUID` 标识。应用保存解析节点、来源及目录事务信息，不保存导入时整份原文件或正文。更新本地塔台时点“重导入”，选择新文件或粘贴新正文；继续使用原塔台 ID。全部同步跳过本地来源。

本地正文与网络订阅复用 Go 解析、过滤及 ContentHash 事务；重复节点合并仍保留来源关联。解析失败、取消或内容校验失败不会用不完整节点替换上次成功的目录。Provider 处理继续遵守现有解析与过滤规则；本地正文不会额外请求其中的远程 provider，未展开部分以导入警告提示。

## 限制与失败反馈

大小受设置中的订阅最大 MiB 限制；文件读取按字节有界，正文按 UTF-8 字节校验。地址及所选文件数量读取“单批地址上限”和“本地文件多选上限”。无效输入或选择超限留在添加面板供修正；已接收任务的文件权限、UTF-8、大小或解析失败写入来源状态，并由底部消息报告失败数量。

来源创建与节点暂存按实际JSON编码字节数自动分批，不限制为16个来源或100个节点；整次提交数量由用户设置控制。每个数组预算900000字节，单次桥接请求上限1 MiB，超大外部节点另走分块。Go解析结果按字节批读，过滤后只回传记录引用与来源信息，不重复传输完整节点。短记录每包可容纳更多条，长记录会提前发送。

名称包含、名称排除保留Kotlin正则语义，例如 `过期|官方` 匹配包含任一词的名称；本次批量优化不改变已有表达式。正式写入仍由单写连接按事务串行执行，WAL允许目录读取与写入同时进行；解析、规范化和键计算不占用整个正式提交事务。

目录查询采用每批至多 100 条、每列表最多 5 批、合计 50 MiB 的窗口约束；远跳按有界批次扫描，不一次加载完整目录。批量选择仅选择已加载项。窗口页、筛选与测量摘要通过修订号、筛选令牌、节点 ID 和请求序列隔离旧结果。

导入与同步共用批次队列。批次按提交顺序执行，批次内部按“塔台并发数”运行固定工作池，“解析并发数”限制同时解析的正文；SQLite 正式写入继续保持串行事务。已有任务运行时可继续添加，最多等待 8 个批次，满时明确拒绝并保留抽屉草稿，不静默丢弃。来源通道容量与塔台并发数相同，不按整批地址数创建协程。

总控显示已完成来源数、已接收来源数、等待批次与活动阶段；来源逐批入队期间总数会增长，不使用它生成虚假的固定百分比。取消停止当前批次并清除等待批次，不撤回已完成事务；同步完成后重读目录，重读失败明确报告数据已提交。运行中批次不因切页主动取消；进程退出后不恢复等待队列。

## 浏览与操作

塔台卡显示来源、真实同步时间、状态及服务端提供的流量信息。只有真实已用量和总量齐全才显示确定比例；同步过程没有实际比例时使用不确定进度。航班数量表示目录有效航班数量，不代替网络可用性结论。

“航班”操作展开来源航班；“更多”打开删除操作。删除先进入底部 Snackbar 的待确认窗口，“撤销”立即取消待删除状态；提示过期或关闭才执行删除。连续删除按消息队列逐项确认，每条撤销与过期动作互斥，旧消息不会重复提交。

塔台和航班搜索默认收起，点击搜索图标展开，取消会清空关键词。航班筛选继续使用浮动按钮和即时生效抽屉。点击航班打开详情，长按选择，读屏也可执行选择动作。详情先呈现真实指标、所属塔台编号、解锁与最近测试，再按需展开协议配置及历史。敏感配置默认隐藏。

除起飞页外保留下拉刷新：目录重读、设置存储重读和日志重读各自报告失败。设置存在待保存变更时不覆盖草稿；等待重读期间发生的新编辑优先于旧读取结果。日志读取失败保留页面错误反馈。

测速与持久后台队列尚未接入；无测试记录时显示“未测试”，不由节点名称推断地区、测速或平台解锁结果。
