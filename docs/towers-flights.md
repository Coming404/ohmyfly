# 塔台与航班使用

应用圆角由 [AppCorners](../ui-shapes/README.md) 集中管理：卡片、内容块、弹窗和输入框采用连续曲率；正圆按钮和胶囊保持真圆／真胶囊。背景、选择覆盖、裁剪与描边使用相同轮廓，控件点击尺寸保持原值。

## 添加与更新来源

塔台页右上角“添加”打开 Miuix `OverlayBottomSheet`。订阅地址／协议链接／YAML 正文、Mihomo YAML 文件、全网打野按同组来源行展示，可独立展开并保留草稿；正文区可滚动，添加按钮固定在抽屉底部。“合并为一个塔台”开关保留，全网打野当前仅占位。

- **订阅地址／协议链接／YAML 正文**：多行输入自动识别 HTTP(S) 订阅、节点协议链接或配置正文。HTTP(S) 来源可再次同步；节点链接与正文交给 Go 解析，同批重复地址合并。输入支持粘贴和行数／字符数显示。
- **Mihomo YAML 文件**：Android/iOS 系统选择器支持多选和逐项移除。选择时只保存本次引用，轮到来源执行时才读取 UTF-8 正文，避免整批文件同时常驻内存。取消系统选择保留原有草稿。

“合并为一个塔台”默认关闭，关闭时每个来源独立建塔台；开启后显示一个塔台并持久保存全部来源。合并塔台的同步更新其中的网络地址，本地来源在“更多”中的来源列表按来源 ID 重新导入。一个来源失败保留其上次成功节点，不清空其他来源。来源之间仍执行基础 ContentHash 去重，来源身份和节点关联分别保存。合并塔台不相加不同套餐的流量额度。

文件和文本来源分别使用 `local:file:UUID`、`local:text:UUID` 标识。应用保存解析节点、来源及目录事务信息，不保存导入时整份原文件或正文。更新本地塔台时点“重导入”，选择新文件或粘贴新正文；继续使用原塔台 ID。全部同步跳过本地来源。

本地正文与网络订阅复用 Go 解析、过滤及 ContentHash 事务；重复节点合并仍保留来源关联。解析失败、取消或内容校验失败不会用不完整节点替换上次成功的目录。Provider 处理继续遵守现有解析与过滤规则；本地正文不会额外请求其中的远程 provider，未展开部分以导入警告提示。

## 限制与失败反馈

点击添加后立即关闭面板，页面通过全局通知提示塔台已加入同步队列；无需再次确认“完成”。任务结果随后显示在塔台卡片和导入结果面板。

固定操作按钮使用有界自动字号，空间不足时在字号下限处省略。异常胶囊、导入提示和连接配置正文允许换行，并随内容增高。全局通知显示在顶部安全区，带撤销动作的通知默认停留 4 秒，其余类型 3 秒；撤销期间后续消息排队，确认前只隐藏待删除卡片。成功、失败、错误和待确认通知分别使用适配浅深主题的语义底色，普通通知保持黑底白字。通知使用 Miuix 默认自适应高度及内置关闭按钮，正文最多两行，超长内容省略；撤销动作仍由同一通知宿主管理。

大小受设置中的订阅最大 MiB 限制；文件读取按字节有界，正文按 UTF-8 字节校验。地址及所选文件数量读取“单批地址上限”和“本地文件多选上限”。无效输入或选择超限留在添加面板供修正；已接收任务的文件权限、UTF-8、大小或解析失败写入来源状态，并由顶部消息报告失败数量。来源处理、批次及下拉刷新的失败记录阶段、异常类型与脱敏原因链；默认信息级别逐次记录 UA 候选、重试、直连／镜像名称和前缀地址、响应状态、下载大小及耗时，汇总原始航班数、各类过滤数和过滤后总数。读取／解析／提交阶段的失败展示在对应塔台上。刷新票据仅传递身份和代际，去重配置由 Go 事务读取，不再跨桥接发送可能包含空集合的规则。

来源创建与节点暂存按实际JSON编码字节数自动分批，不限制为16个来源或100个节点；整次提交数量由用户设置控制。每个数组预算900000字节，单次桥接请求上限1 MiB，超大外部节点另走分块。Go解析结果按字节批读，过滤后只回传记录引用与来源信息，不重复传输完整节点。短记录每包可容纳更多条，长记录会提前发送。

名称包含、名称排除保留Kotlin正则语义，例如 `过期|官方` 匹配包含任一词的名称；本次批量优化不改变已有表达式。正式写入仍由单写连接按事务串行执行，WAL允许目录读取与写入同时进行；解析、规范化和键计算不占用整个正式提交事务。

目录查询采用每批至多 100 条、每列表最多 5 批、合计 50 MiB 的窗口约束；正常切页保留两侧的有界窗口，名称搜索与航班筛选只使各自列表失效，隐藏页面不取消当前页查询。远跳按有界批次扫描，不一次加载完整目录。批量选择仅选择已加载项。窗口页、筛选与测量摘要通过修订号、筛选令牌、节点 ID 和请求序列隔离旧结果。

导入与同步共用批次队列。批次按提交顺序执行，批次内部按“塔台并发数”运行固定工作池，“解析并发数”限制同时解析的正文；SQLite 正式写入继续保持串行事务。已有任务运行时可继续添加，最多等待 8 个批次，满时明确拒绝并保留抽屉草稿，不静默丢弃。来源通道容量与塔台并发数相同，不按整批地址数创建协程。

总控只在库内存在塔台时显示，汇总塔台数、航班总数、已用流量和真实批次状态；三项主读数使用 18 sp。点击卡片空白或标题区展开／收起七日趋势，箭头仅表示当前状态；图表和同步按钮保留各自交互。来源阶段及不确定进度显示在对应塔台卡片中。取消停止当前批次并清除等待批次，不撤回已完成事务；同步完成后重读目录，重读失败明确报告数据已提交。运行中批次不因切页主动取消；进程退出后不恢复等待队列。

## 通用同步状态

新建来源落库后立即重读塔台卡片，下载、解析与提交阶段在对应卡片显示；每个来源完成后再次更新卡片。整批结束由根级通知宿主报告成功／失败数量，关闭添加抽屉或切换页面不会丢失完成通知。
来源请求失败只在对应塔台、总控状态和批次通知中反馈；目录打开或列表读取失败才显示列表级错误及重试按钮。塔台卡的来源与真实同步时间文本与名称左侧对齐，并显示正常／同步中／异常状态、航班总数、套餐使用量和到期绝对日期；过期显示“已过期”。三个底部操作等宽、等高，字号和图标一致。流量条剩余超过 20% 时深绿、20% 以内为橙、耗尽或过期为红；套餐流量与总流量使用十进制 B、KB、MB、GB、TB。同步期间塔台卡显示不确定进度，不伪造百分比；待同步、同步中或同步失败时航班入口禁用并显示灰色。更多使用单选下拉菜单，提供编辑名称／订阅地址、复制订阅地址、导入结果、删除；编辑、结果、删除与合并来源管理分别进入对应抽屉。

塔台标题、数量胶囊与右侧搜索／添加固定在顶栏，总控卡和塔台卡片随同一列表滚动。航班页分组与搜索同样随列表滚动，首项与顶栏的间距同塔台页一致。两页普通态和选择态标题均采用 17 sp 胶囊，胶囊、工具栏和独立按钮统一为 44 dp 基准高度；文字型控件随字体缩放自然增高。航班列表占满页面视口，底部导航安全区放在列表内容留白中，滚动时卡片可从导航栏下方经过。所有现有下拉刷新入口使用 Miuix 的 35% 触发阈值和中文状态提示；塔台下拉刷新清除目录窗口缓存后重读 SQLite 已保存的名称、地址、航班数量、状态、时间和套餐用量，不发起订阅同步。需要重新下载时使用单塔台“同步”或总控“全部同步”。

塔台和航班搜索默认收起，点击顶栏搜索入口展开并聚焦一次；塔台列表同时定位至搜索框。切换主页面前释放焦点并收起键盘：空白查询收起搜索框，非空查询保留搜索框、内容和筛选条件，返回页面及懒列表重建均不主动聚焦。搜索框与卡片左右对齐，不显示外置“取消”按钮；框内 X 与再次点击顶栏搜索入口都关闭搜索、清空关键词并收起键盘。塔台搜索只匹配名称；航班搜索按名称和筛选条件工作。航班筛选入口与搜索合并在顶部右侧的横向 FloatingToolbar，打开后仍使用即时生效抽屉；底部不再显示独立筛选按钮。航班页支持固定状态筛选和自定义分组：分组可添加、重命名、删除，节点可单选或多选移动到分组；没有自定义归属的航班默认属于“全部”分组，移动后仅在目标组显示。分组胶囊的数量按名称／协议搜索结果统计，不随当前选中的分组或运行状态隐藏其他组的计数。分组、节点唯一归属、移动顺序和查询计数由 SQLite 持久化，全库分页筛选不依赖当前缓存页。移动分组后先重读列表、计数和详情，再结束操作，原组不再保留该航班；航班删除在同一事务中解除所有来源引用，再删除节点及其级联元数据。塔台与航班均可同时展开多张卡片；进入选择模式时收起航班详情。加载状态使用塔台卡片和航班行骨架；搜索无结果可清除搜索／筛选，无航班时可直接前往塔台页。

航班详情在卡片内展开，呈现真实指标、所属塔台、所属分组、平台解锁状态和最近测试。协议详情按具体节点的字段动态显示原始字段名与值，不翻译协议键；敏感配置默认隐藏，用户选择显示后才展示完整节点信息。历史结果按需读取。地区代码明确存在时通过 kmp-flagkit 1.1.0 显示旗帜，未知地区不猜测。

塔台的搜索／添加、航班的搜索／筛选分别组成顶部右侧的横向 FloatingToolbar，双按钮表面为 92 × 44 dp，图标 20 dp，单按钮点击区 44 × 44 dp，按钮间距 4 dp；工具栏宽度由内容撑开。工具栏内容表面复用设置中的界面材质及减少透明效果策略，不为每个按钮叠加独立背景。

顶部、底部选择工具栏复用 Miuix FloatingToolbar 和 IconButton；顶部为横排取消／全选，两页底部共用 268 × 60 dp 基准尺寸，动作平分宽度，统一由界面材质设置控制内容表面。分组胶囊随列表滚动，使用 12 sp 标题、11 sp 数量和 30 dp 可见高度，保留 44 dp 点击高度；未选中使用次要文字色和常规字重，选中加粗，颜色切换过渡 160ms，减少动态效果时直接切换。右侧加号独立使用当前界面材质和强调色。设置中的独立图标动作同样使用统一材质与尺寸；列表内动作采样独立底色图层，不反向采样包含自己的整页图层。空状态在可用列表视口中居中，提供放大图标、标题、上下文说明与下一步操作。航班卡片、内嵌航班行及长按指示统一裁剪到连续曲率轮廓；选中后以浅蓝薄覆盖和细边框标识，选择框与整行垂直居中。

长按塔台或航班进入对应多选模式，顶部显示数量、取消和跨页全选，底部使用浮动工具栏。航班页全选当前筛选结果；塔台内全选当前来源航班，切换塔台时重新开始该塔台的选择。目录版本、搜索范围或航班筛选更新后清除旧选择。多选期间收起航班详情。

塔台多选支持同步和删除。批量同步一次提交为一个目录批次，共用来源与解析工作池，退出选择模式不会取消任务；本地文件／文本来源仍需重新导入。批量删除使用独立确认面板，保留其他来源仍引用的节点。

航班多选支持启用／停用、移动分组、分享和删除；停用节点不加入新的任务。删除节点会移除其来源关联及记录，后续订阅同步可能重新导入。单航班和多航班均可复制 YAML 或打开系统文件分享；导出每批读取 100 个配置并合并成同一份 Mihomo `proxies:`，超过一批的选择不会截断。

除起飞页外保留下拉刷新：目录重读、设置存储重读和日志重读各自报告失败。设置存在待保存变更时不覆盖草稿；等待重读期间发生的新编辑优先于旧读取结果。日志读取失败保留页面错误反馈。

测速与持久后台队列尚未接入；无测试记录时显示“未测试”，不由节点名称推断测速或平台解锁结果。

## 节点地区

节点名称支持中英文国家名、城市及常用别名、名称中已有的国旗标记，以及两字母代码。例如 `Hong Kong`、`hongkong`、`HK`、`香港` 均显示为“香港”，`Tokyo`、`东京` 显示为“日本”，`狮城` 显示为“新加坡”。英文忽略大小写并检查字母边界；优先匹配最长名称／别名，其次识别有效国旗标记，最后匹配代码。`USA`、`UK`、`UAE` 等非标准缩写作为补充别名；`LA` 保留老挝含义，洛杉矶使用中文或英文全名识别。Go 只输出地区代码和中文名，界面继续使用 kmp-flagkit 图标。

名称地区与手动地区分别保存，有效值按名称、手动、未知取值；尚未提供手动地区编辑入口。目录数据库升级至 v4 时，每批 100 条按当前别名重识别已有节点，覆盖 v1/v2/v3 中缓存为未知的 `hongkong`；仅更新名称地区。目录同步、结果回填及版本标记同事务提交，失败全部回滚。后续启动不重复写目录或回填，订阅刷新仍原子更新对应节点。地区属于独立应用元数据，不写入协议配置、不参与 ContentHash，也不从平台解锁地区取值。

现有 248 项国家及地区目录均提供英文识别名和中文显示名；另增特殊标签 `CloudFlare`。`cloudflare`、`cf` 忽略大小写后统一显示为 `CloudFlare`，国旗槽使用内置的 CloudFlare 原色云朵图标。`CF` 按此约定优先表示 CloudFlare，中非通过 `Central African Republic`、“中非共和国”或对应国旗标记识别。其他已识别地区使用独立代码查询国旗，未知地区显示“未知”。
