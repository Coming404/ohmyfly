# Agent Note: 真机反馈后的双端体验修正提案

Status: proposed

## Problem

iOS 真机反馈提出12项布局、材质、性能、状态栏、字体、弹层、设置和震动问题；既有双端编译通过不能替代这些设备验收。用户当前要求先给文档，不授权本轮运行时代码、推送或再次构建。

## Proposal

以[真机反馈修正方案](../../../../docs/device-feedback-rework.md)为本轮唯一详细计划，保留原反馈编号、官方/参照/现值/目标区别、待测假设和阶段验收。按平台触控→紧凑布局→玻璃性能→即时编辑→弹层运动→震动回归分阶段执行，后续实施需确认。

2026-10-21：用户授权先按[局部交互规格](../../../../docs/design/mirror-settings/PRD.md)、九张独立图及流程总览还原第8项中的镜像源页。该局部由[镜像页实现决定](../../implemented/feature/2026-10-21-mirror-settings-page.md)接管；最新要求为拼接方式普通行不带卡片、新增／编辑弹窗底部手动保存，输入／失焦／关闭不提交。第8项其他设置页面及其余11项仍为提案，不随局部源码实施标记完成。

历史审计：与[紧凑顶栏](../../implemented/feature/2026-10-19-compact-page-header.md)、[悬浮底栏](../../implemented/feature/2026-10-20-stacked-bottom-navigation.md)、[Melox玻璃](../../implemented/feature/2026-10-20-melox-glass.md)、[选择菜单](../../implemented/feature/2026-10-19-preset-selection-popup.md)、[运动策略](../../implemented/feature/2026-10-20-reduced-motion.md)、[设置导航](../../implemented/architecture/2026-10-20-settings-navdisplay.md)均部分重叠。旧记录仍描述当前代码；只有获准实施且验证后，才更新被替代的几何、动效和交互决定，未提前归档或改为完成。

## Alternatives considered

- 原样照搬Melox：参照一致性高，但64dp高度、0.4覆盖与最小100dp单项宽不能自动解决本次诉求；只复用适用参数和既有共享效果。
- 继续只用高层官方选择行：维护成本最低且目前右值/双箭头已正确，但固定0.9.4没有同时调整材质、动画、灰幕的公开高层入口；拟只在ChoiceSetting边界用公共低层PopupLayout适配，复用行/选项/ID/唯一设置值。不是因外观喜好重写整套组件。
- 每字符或纯防抖自动保存：可能把未输入完的 URL 落盘；原即时编辑建议不适用于用户最新确认的镜像新增／编辑，这两个表单改为底部手动保存并使用 Session 的真实事务确认。其他设置文本即时编辑仍属未来提案。
- 直接新增动画/震动/模糊库：可能减少局部实现，但尚无现有能力不足的证据，先用现有Compose/Miuix与平台适配；新增依赖另做Klibs核验。
- 删除整条顶部安全区或即时保存每个输入字符：可显著收紧/减少按钮，但会覆盖系统UI、损坏未完成URL/数值，故保留系统避让和合法值提交契约。

## Acceptance criteria

详细计划覆盖全部12项、六阶段、前后参数、Miuix弹层类型、设备验证与来源；只产生文档文件，结构/链接检查通过。运行时功能、视觉与性能尚未验收，不写为修复完成。

## Risks

卡顿/触控/长按实化尚需设备时间线或消融；Miuix部分材质/遮罩/动画公开入口有限，不能承诺一参数全局覆盖；现有iOS系统字体链应先验证字重/回退而不是盲目重打包字体。120fps按设备实际刷新率测量，不作无证据保证。
