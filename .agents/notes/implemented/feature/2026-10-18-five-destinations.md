# Agent Note: 五入口悬浮导航与固定品牌顶栏

Status: implemented

## Problem

现有概览、节点、外观是三页展示样板。用户确定正式菜单为概览、订阅、测速、节点库、设置，并选择悬浮胶囊底栏与固定品牌顶栏；页面操作应跟随目的地，而不是所有页面使用同一批按钮。

## Decision

- 使用锁定 Miuix 0.9.4 的 FloatingNavigationBar / FloatingNavigationBarItem，五个具名目的地替代整数下标。保留图标导航的可访问名称，并提供长按文字提示。
- SmallTopAppBar 固定显示 ohmydrift 和装饰品牌图标，副标题显示当前页面；右侧只暴露已有可执行操作：节点库的分类全选/全局清空、设置的概览预览。
- 外观页收敛为设置页，移除纯字体/色块展示。节点库批量操作移到顶栏，保留原有分类与选择契约，避免重复入口。概览提供四个功能页快捷入口。
- 订阅、测速先提供独立页面与明确的未接入状态。无订阅数据，不伪造导入、开始/停止或历史结果；测速页可查看当前选择的演示节点，但不能启动网络请求。
- 保留共享 Miuix、主题、概览顶栏模糊及减少动态效果边界；不新增依赖、不提交/推送/构建/下载产物。

## Related decisions

[统一悬浮材质与系统配色](../bug-fix/2026-10-19-floating-chrome.md)替代本篇的全宽SmallTopAppBar、仅概览模糊及全局Crossfade；[生产界面清理](../simplification/2026-10-19-production-ui.md)移除运行时夹具与开发提示。五个目的地、选择契约和完整模块要求保留。

检索现有活跃笔记：与[共享 UI 展示](../../implemented/feature/2026-10-18-ui-showcase.md)部分重叠，保留会话状态、演示数据、无后端和选择语义；新的五页/导航形态替代三页。与[Expressive 概览](../../implemented/feature/2026-10-18-expressive-overview.md)部分重叠，保留主题与模糊，更新快捷入口。基础架构提案和工程底座继续有效；Release流程提案与本次导航无关，不重写。

## Alternatives considered

- 标准全宽图标加文字底栏：可发现性更高，但用户明确选择悬浮胶囊；用当前页副标题、图标命名和长按提示弥补图标导航限制。
- 订阅、节点库、测速、结果、设置：结果独立便于历史分析，但用户选择保留概览；不擅自加第六个菜单。
- 立刻实现导入与真实测速：更快进入完整业务，但需要解析、安全存储、Go核心和任务生命周期契约，不能作为导航调整附带实现。

## Consequences

- 五个目的地顺序/名称固定为概览、订阅、测速、节点库、设置，分别持有列表位置；节点选择与主题继续由共享入口持有。
- 节点库批量操作只影响当前分类，全局清空独立；空分类与无选择时分别禁用。图标有名称和长按提示，顶栏动作触区48dp；订阅与测速未接入状态明确，不会触发网络请求。
- 旧 AppearanceScreen、三项底栏、节点页内重复批量按钮、设置页字体色块展品已删除，不留双实现。
- 结构检查、19个Python测试、git diff --check通过。新增2个AppDestinationTest检查顺序与图标唯一性，尚未运行Kotlin测试/完整编译，不声称真机通过。
- 五图标胶囊的可发现性、小屏横竖屏安全区、长副标题、读屏和大字体仍需真机验收。完整构建只在用户要求新包时执行。
- 用户后续追加“引入全部 Miuix 模块、图标完整引用”，由[全模块接入](2026-10-18-miuix-full-modules.md)落地；该依赖扩展不受本篇初次导航实现“不新增依赖”的范围限制。
