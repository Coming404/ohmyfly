# Agent Note: GitHub 镜像页交互精修

Status: implemented

## Problem

镜像页精修反馈覆盖设置行紧凑度、关闭开关后的依赖操作、单一测试按钮、排序控件、弹窗材质、拼接方式选择和页面标题。此前页头右侧排序循环图标、测试失败时额外的“重试失败项”按钮，以及把镜像弹窗绑到全局材质的实现，与当前期望不符。

## Decision

- 设置行当前值与尾随尖头之间固定保留 8dp。镜像页标题使用与设置子页相同的 18sp Semibold。
- 镜像开关在列表为空时仍可启用；停用只更改开关，不清空配置，空列表下请求仍安全直连。停用时，镜像列表、恢复草稿、测试按钮和新增入口均不可操作并出现淡灰遮罩；顶栏新增按钮遵循 Miuix disabled 样式。若测试已经运行，停止操作保持可用。
- 移除镜像源卡头排序切换图标。维持现有持久化排序字段与读写兼容；管理内移动依据当前可见顺序提交镜像列表并切换为 Manual，测速排序仍在旧排序状态下按交互冻结规则更新。
- 删除单独的失败项重试按钮，只保留全量测试／停止按钮，图标文字间距采用 8dp。
- OverlayDialog 使用 Miuix `DialogDefaults` 默认表面，不再调用 chromeMaterial；弹窗后方保留 2dp Compose 高斯模糊，不加灰幕。拼接方式使用公开 `OverlayDropdownPreference` 默认下拉表面，已存的 Template 显示禁用“原模板”选项，用户仍可显式改为 HTTP(S) 前缀。

## Alternatives considered

- 保持空列表时开关强制禁用更简单，但用户需要先添加镜像才能启用该设置，且配置开关与资源可用数量被混为一谈；保留独立开关，让空列表时资源层直接回退。
- 为保持原下拉外观继续手绘覆盖菜单，能精准控制单项布局，但重复 Miuix 的选择语义、默认间距与展开／关闭状态；改用受支持的官方下拉组件。
- 将仍在运行的测试也一并遮挡禁用，会阻断用户取消耗时工作；仅停止按钮在活动期间保持可用。
- 删除排序模型及持久化字段可减少代码，但会扩大落盘格式迁移范围；本次仅删除用户要求移除的切换控件，排序字段仍兼容并由手动移动设置为 Manual。

## Consequences

设置项禁用由同一镜像开关状态决定，浮层阻止指针穿透；Miuix 控件自身仍接收 disabled 语义。单列表排序和手动排序共享已有稳定 ID、SettingsSession 与原顺序事务，不新增依赖或设置字段。

Kotlin 回归补充覆盖空列表仍启用、启用但空列表时直连、按可见排序手动移动；共享测试声明数及 CI 门槛同步为 176。项目 PRD 与上一版镜像页 Note 已同步。静态检查通过不代替双端编译与真机视觉／读屏验证；弹窗默认 surface、遮罩对比度和停用状态仍需 Android/iOS 设备确认。
