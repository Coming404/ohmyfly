# Agent Note: 紧凑页面标题与纯图标返回

Status: implemented

## Problem

用户授权设置改造第4项，明确一级标题不要太大、子页返回必须纯图标。当前顶栏仍把Wave、ohmydrift、当前页副标题、文字返回和动作放在同一个品牌胶囊；节点库内容区另有同名标题。原设计28sp大标题/20sp紧凑标题不再适用。

## Decision

- 一级/子页统一18sp Semibold单行标题，不新增大标题、双标题或滚动字号切换；保留系统字体缩放、heading语义、长标题省略及完整读屏文本。
- 删除顶部品牌标记、品牌文字和副标题层级；品牌身份只保留在设置首页。标题本身无胶囊、描边或阴影。
- 子页返回复用现有HeaderAction的官方IconButton/TooltipBox/48dp触区；官方Basic.ArrowRight按LTR镜像为返回方向，RTL不镜像；仅变换图形，保留按钮点击与“返回”读屏名称，不显示文字返回。
- 根App继续决定目的地标题、子页返回及系统返回。节点库两个真实批量动作保持禁用条件与回调；可空actions只在有真实动作时创建末端控件容器，设置首页不出现空胶囊。
- 顶栏仍在根Scaffold槽位，顶部/横向safeDrawing只处理一次，左右16dp、上下8dp、主体至少48dp，大字体自然增高。标题与功能按钮分离，只有功能按钮容器复用原ChromeMaterial，材质参数及底栏不改。
- 为避免滚动正文穿过裸标题降低可读性，顶端使用当前页面色的基础渐隐底（0–80%不透明、末20%到透明），覆盖安全区；这是普通颜色渐变，不是新模糊/折射预设。内容视口与Backdrop捕获边界不改。
- 删除节点库内容内重复“节点库”标题，其余真实分区标签不变。第5/6/7项及业务、配置、导航架构不扩展。

## Existing decisions audit

[设置NavDisplay接入](../architecture/2026-10-20-settings-navdisplay.md)部分替代本篇旧的SettingsBackHandler返回接线：顶栏外观/18sp/纯图标/48dp不变，返回改为唯一栈与镜像本地动作优先，统一系统/预测返回并按需启用滑退。本篇原39项守卫为当时证据，当前累计数量见新决定。

- [统一悬浮材质](../../implemented/bug-fix/2026-10-19-floating-chrome.md)：部分替代品牌胶囊布局；保留单采样源、列表contentPadding、原功能材质及减少透明回退。
- [五入口](../../implemented/feature/2026-10-18-five-destinations.md)：五个目的地、节点选择与图标依赖保留，顶栏品牌/副标题被替代。
- [官方预设选择弹层](../../implemented/feature/2026-10-19-preset-selection-popup.md)：继续复用根Scaffold，弹层及返回优先级不新增竞争处理器。

## Alternatives considered

- 官方大标题滚动折叠：可表达层级，但用户刚明确不要太大，还会增加滚动依赖和重复标题，不做。
- 仅把胶囊里的ohmydrift改成页名：改动最少，也保留可读性，但仍是标题/功能混杂的胶囊，不符合本轮去品牌容器方向。
- 无任何底色的裸标题：最轻，但当前列表可滚到顶部后方，正文可能干扰标题；采用页面色窄渐隐，不新增复杂效果。

## Consequences

- 顶栏只持有展示参数，不新增导航/滚动/主题状态。App仍是目的地、子页与节点选择唯一来源，Android系统返回原处理器未改；可空动作槽避免无动作页的空材质容器。删除旧品牌层级、文字返回和节点库重复页名，不留双实现。
- 官方IconButton默认40dp最小触区（已载入Miuix Skill图标指南），项目原HeaderAction明确48dp；本轮返回复用同一48dp按钮，图形24dp。18sp标题、48dp主体、16/8dp外边距及页色渐隐是应用设计值，已同步方案对照表。使用已有公开组件及已核对的ArrowRight，不重复联网或新增依赖。
- 新增5项Python结构接线守卫，累计39项Python通过，结构与diff检查通过；检查覆盖标题/heading/无品牌、纯图标返回与RTL/48dp、原导航回调、真实动作条件、安全区/内容捕获接线。测试不运行Compose语义树或像素渲染，不能当成真机通过。
- Kotlin测试仍68项声明未运行；Kotlin/Android/iOS编译、系统/弹层返回优先级、大字体/长标题/渐隐可读性和动画性能等待后续授权。没有新自定义动画，本轮不提交、推送或构建。第5/6/7项未开始。
